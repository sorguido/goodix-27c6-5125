# Private workspace archive

This directory preserves material excluded from the public source surface:
internal governance and chronology, analysis and evidence, private captures,
OEM/protected artifacts, vendor firmware, historical harnesses, superseded
implementations, generated caches, and host-local build payloads.

It is intentionally ignored by Git in the current working tree. The private
repository history remains unchanged and is not a publication input.

Nothing outside this directory may import, build, test, install, or document a
runtime dependency on its contents.
