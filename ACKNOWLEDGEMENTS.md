# Acknowledgements

## Rockytkg

This project gratefully acknowledges the work of
[Rockytkg](https://github.com/Rockytkg/goodix-linux-27c6-5125). That project
was an invaluable technical reference and an essential point of orientation
during development. It helped make several components and implementation
paths understandable that would have been substantially harder to reconstruct
without an existing body of work to study.

This project follows a factory-preserving path and has its own architecture,
target-specific evidence requirements, and qualification process. Those
differences do not diminish the importance of Rockytkg's earlier work or the
help it provided. Licensing, attribution, and source provenance are recorded
separately in [Licensing and provenance](docs/LICENSING_AND_PROVENANCE.md) and
[Upstream references](docs/REFERENCES.md). This acknowledgement does not imply
endorsement by or of either project.

## Development tools

OpenAI AI tools were used as development aids. ChatGPT supported analysis,
review, documentation, and technical reasoning. Codex supported
implementation, repository changes, and code and repository review.

Human contributors retained responsibility for the project, including final
decisions, hardware testing, safety gates, and approvals.
