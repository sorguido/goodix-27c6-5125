# Goodix Manager 3.0.1 — draft, not released

This update removes the Fedora-version restriction from Goodix Manager.
Version 3.0.1 has been tested on Fedora KDE 44 and 45, as reported by the operator.

**Install 3.0.1 on Fedora 44 before upgrading to Fedora 45 or later.** You do
not need to uninstall the fingerprint driver, and fingerprints enrolled with
version 3.0.0 remain usable. Migration from SIGFM 2.x requires new enrollment.

Compatibility with future Fedora versions depends on their system components.
Dependencies and runtime compatibility checks still apply.

Version 3.0.1 is being prepared as an unpublished draft and is not publicly
downloadable until publication. See [validation](VALIDATION_3.0.1.md) for the
distinction between tested packaging revisions and the final release artifacts.
